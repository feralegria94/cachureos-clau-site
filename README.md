# Cachureos Clau — Sitio de Tienda

Sitio web comercial para tienda de cachureos (artículos de papelería, hogar y vajilla) en Chiloé.

**Demo:** Pendiente de deploy público

## Qué es

Landing page de tienda con catálogo visual, envíos y SEO optimizado. Diseño responsive con identidad de marca propia.

## Stack

- HTML5 semántico
- CSS3 responsive (mobile-first)
- JavaScript vanilla (carrusel y animaciones)
- SEO: sitemap.xml, robots.txt, meta tags

## Estructura

```
├── index.html          # Landing principal con hero y catálogo
├── envios.html         # Página de información de envíos
├── assets/
│   ├── css/styles.css  # Estilos principales
│   ├── js/scripts.js   # Interacciones (carrusel, menú)
│   └── img/            # Imágenes y logos de marca
├── sitemap.xml
└── robots.txt
```

## Diseño

- Paleta de colores cálida (identidad de marca)
- Responsive: desktop, tablet y móvil
- Galería de productos con imágenes WebP optimizadas
- Menú de navegación con íconos
